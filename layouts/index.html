go-ruby-opentype is the pure-Go, Ruby-runtime-independent core of the Ruby opentype gem: a complete text stack — font parsing, sized faces, complex-script shaping, the Unicode Bidirectional Algorithm and a registry of legible fonts — shaped so that go-embedded-ruby (rbgo) can bind it as require "opentype". It is a thin adapter over the typed libraries of the go-opentype stack — opentype (parse + raster), shape (the HarfBuzz-lite complex-text shaper), bidi (UAX #9) and fonts (bundled families) — exposed through Ruby-facing handles (Module, Font, Face) whose methods return Ruby-shaped values: a Hash, an Array or a scalar. A single dynamic entry point, Call, dispatches a snake_case method name to the matching handle method, which is exactly what an rbgo binding drives from method_missing. No cgo, no HarfBuzz, no FreeType, no x/image or x/text anywhere in the stack — 100% coverage, CI green across amd64, arm64, riscv64, loong64, ppc64le, s390x and js/wasm.

require "opentype"

font = Opentype.open_font(Opentype.most_legible)
face = font.face(24)
face.measure("Hello")                      # => Integer

Opentype.shape(face, "بيت").each do |g|    # => Array<Hash>
  # draw glyph g["gid"]; advance the pen by g["x_advance"]
end

Opentype.visual_order("aب1", "auto")       # => reordered String
Opentype.families.map { |f| f["name"] }    # => 44 bundled family names

A sibling of go-ruby-regexp, go-ruby-erb and go-ruby-dimail in the go-ruby-* family: the interpreter-independent core of a Ruby library in pure Go, cgo disabled, so it cross-compiles and embeds anywhere. The typed font parser, shaper, bidi engine and font registry live in go-opentype; this repo is the Ruby-idiomatic, Hash-and-Array-returning adapter that github.com/go-embedded-ruby binds.
